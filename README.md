# אלבום הבלוז — ChelseaGame

אלבום מדבקות דיגיטלי ומשחקונים לאוהדי צ'לסי צעירים. עברית מלאה, RTL, עובד אופליין.

## הרצה

```bash
npm install
npm run dev          # פותח על http://localhost:5173, וגם זמין מהטלפון באותה רשת
```

| פקודה | מה היא עושה |
| :--- | :--- |
| `npm run dev` | פיתוח עם רענון חי |
| `npm run build` | בונה ל-`dist/` |
| `npm run preview` | מגיש את ה-build, נוח לבדיקה בטלפון |
| `npm run server` | מריץ את שרת הביניים (חדשות ומשחקים) |
| `npm run android` | build ← סנכרון Capacitor ← פתיחת Android Studio |

**מצב אדמין:** הוסף `?admin=1` לכתובת. מקבל 99,999 מטבעות וסרגל עם מילוי אלבום,
פתיחת לוקר, קלפי לוקסוס ואיפוסים.

## עריכת תוכן

ארבעה כלים שנפתחים בדפדפן בלחיצה כפולה, בלי התקנה:

* `tools/sticker-studio.html` — כל 118 המדבקות: שם, תמונה, קטגוריות חדשות
* `tools/squad-studio.html` — סגל ואגדות, כולל משיכת תמונות מוויקישיתוף
* `tools/kit-studio.html` — הרכבת ערכות משכבות ויקישיתוף
* `tools/fill-studio.html` — השלמת תמונות אצטדיון וערכות

כל כלי מייצא קובץ שמחליף את המקביל לו ב-`src/data/`.

## שרת הביניים

מגיש פוסטים מאינסטגרם ולוח משחקים. ראה `server/README.md`.
כדי לחבר את האפליקציה: `cp app-config.example.js app-config.js` ועדכן את `apiBase`.
בלי הקובץ הזה האפליקציה עובדת עם תוכן לדוגמה.

## אנדרואיד

```bash
npx cap add android
npm run android
```

## רישוי נכסים

תמונות השחקנים והאגדות מוויקישיתוף ברישיון חופשי, עם מסך קרדיטים באפליקציה
תחת האלבום. הכדור וסמל האריה הם נכסים פרטיים שהוזנו ידנית. הסמל המצויר
על הערכות הוא ציור מקורי ולא סמל המועדון הרשמי.
זהו פרויקט אוהדים אישי ולא מסחרי.

## הערה על הפיצול

הפרויקט נולד כקובץ HTML אחד. `tools/split.mjs` הוא הסקריפט שפיצל אותו למודולים:
הוא חותך לפי כותרות הסקשנים, מזהה אילו שמות כל מודול מגדיר ואילו הוא שואל
מאחרים, ומייצר את ה-import/export. משתנים שמודול אחד מגדיר ואחר משנה עברו
ל-`core/mut.js`, כי ייבוא ב-ES modules הוא לקריאה בלבד. הסקריפט נשמר להיסטוריה
ולא נחוץ יותר.
